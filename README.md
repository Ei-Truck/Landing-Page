# Landing Page - Ei Truck

Um projeto de Landing Page responsiva e moderna, desenvolvida para apresentar o projeto Ei Truck. O foco principal mostrar nossa ideia, explicar um pouco sobre seu desenvolvimento e também sobre o conceito de telemetria

## Tecnologias Utilizadas

* **HTML5:** Para a estrutura e semântica do conteúdo.
* **CSS3:** Para a estilização e responsividade do layout.
* **JavaScript:** Para interações e animações.

## Como Executar Localmente

Siga estas instruções para ter uma cópia do projeto rodando em sua máquina local para fins de desenvolvimento e testes.

## Dependências Principais

- **Navegador Web moderno** (Chrome, Firefox, Edge, etc.)
- **Editor de código** (VS Code, WebStorm, etc.)

## Instalação

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Ei-Truck/Landing-Page.git
    ```
2.  **Entre no diretório do projeto:**
    ```bash
    cd Landing-Page
    ```
3.  **Abra o arquivo `index.html`:**
    
    Execute o arquivo e abra o seu navegador.
